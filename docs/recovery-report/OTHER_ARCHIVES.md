# Independent archive findings

**Updated:** October 16, 2026. This is a focused cross-archive check, not proof that every web archive was exhausted. Machine-readable results and capture provenance are in [OTHER_ARCHIVES.json](OTHER_ARCHIVES.json).

Arquivo.pt returned 35 domain-index rows. Three valid responses were acquired: a 2019 Squarespace homepage, a 2019 blog listing, and a favicon. The blog listing contains twenty visible cards, including eighteen internal post URLs. Arquivo.pt's exact-history endpoint returned no captures for those eighteen permalinks; their article HTML is already represented by Common Crawl captures. The acquired Arquivo.pt files remain in the local recovery checkpoint until reviewed and promoted.

Archive.today's domain index revealed one January 2, 2013 homepage snapshot (`TpBHi`). Its listing page was readable once, but subsequent access to that site and tested mirrors returned a CAPTCHA/security response (HTTP 429). No snapshot bytes were acquired.

Archive-It's public full-text index surfaced a September 19, 2009 Blue Scholars Twitter profile in collection 194. I viewed the replay in a browser: it shows Seattle as the location, links the official site, names Sabzi and Prometheus Brown, and displays archived posts. Related results include a 2017 Twitter profile, a 2009 MyBelltown article, and a 2019 Seattle Film + Music page. These are separate contextual sources; they are not original site pages. The Archive-It `/all` CDX endpoint returned HTTP 403, while an individual replay and public search worked. A collection-specific CDX call from the command-line client received an interactive verification page.

The Library of Congress web-archive catalog returned zero results for `bluescholars.com`, `Blue Scholars`, and `bluescholars`. Its separate wildcard replay endpoint returned HTTP 403 from this environment, so no archive-wide absence conclusion is possible. The University of Edinburgh reports that UK Web Archive captures have been unavailable since March 2025 after a cyber attack. Trove's search/replay entry points returned an anti-bot page. Ghostarchive's exact homepage query returned “No archives for that site.”

The last intact Wayback homepage capture currently indexed is September 30, 2023 (`20230930162408`). Its original HTML is 35,249 bytes with SHA-256 `2a93b4e0fead67e0cdcd76e7fee445a04762ae588c4c15f54e2cc5eb978b9e23`; it is byte-identical to the Common Crawl copy from September 27, 2023. A desktop browser comparison of the 2021 baseline and this later capture showed the same logo, navigation, hero photograph, crop, and layout. The capture was preserved with a per-resource compatibility review; the site-wide release flags remain false.

Official access guidance: [Archive-It CDX/C API](https://support.archive-it.org/hc/en-us/articles/115001790023-Access-Archive-It-s-Wayback-index-with-the-CDX-C-API), [Library of Congress URL-search guide](https://www.loc.gov/programs/web-archiving/for-researchers/searching-the-web-archive/), and [UK Web Archive availability notice](https://library.ed.ac.uk/heritage-collections/collections-and-search/archives/digital-archives-and-preservation/web-archiving/frequently-asked-questions).

## LiveJournal and Common Crawl captures

The separately hosted `bluescholars.livejournal.com` journal is now available under the distinct local `/lj/` section. Wayback supplied a full 2011 front-page capture (`20110812180628`) and individual captures of “friday mixdown” (`16954.html`, captured `20090125012333`) and “The Program” (`17222.html`, captured `20110812180252`). The 2011 front page contains six complete visible entries from 2007–2008; four do not have standalone article captures in the exact-URL searches. Common Crawl adds a 2010 root response (navigation only) and a 2009 profile.

The individual recovered post pages preserve the visible original markup and comments. Twenty linked 2007–2008 photos from Massline Media were recovered and are served locally. Nine ATL image URLs have duplicate 2007 and 2008 captures with identical bytes. The Eventful poster has only later Wayback captures from 2014 and 2021 (same 57,465-byte SHA-256 `8a711dbbdb9c19dea8f86b5b699019920a3ed99b371e819a9e96c492ce1d367f`); it remains held out until its date compatibility is reviewed. The remaining `http://masslinemedia.com/news/newspics/213.jpg` capture is only a 114-byte HTML redirect to Wayback’s `/lander`, not an image. Common Crawl and Arquivo.pt exact-URL checks returned no image bytes, so the lander was not bypassed.

The original LiveJournal CSS bundle was not recovered: an exact Wayback replay request for the 2011 bundle returned HTTP 404. The pages therefore retain sanitized source markup with local restoration styling, not a verified recreation of LiveJournal’s original presentation. The full source hashes, capture timestamps, route mappings, query scope, and limitations are recorded in [OTHER_ARCHIVES.json](OTHER_ARCHIVES.json). These hosted journal pages remain separate from the three official Blue Scholars website generations.
