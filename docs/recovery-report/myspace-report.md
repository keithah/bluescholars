# Blue Scholars MySpace profile recovery

The separate profile archive is [myspace.com/bluescholars](https://myspace.com/bluescholars). Exact Wayback CDX queries covered the apex and `www` on HTTP and HTTPS. They returned 91 unique successful HTML capture rows spanning 2007–2025. Each date was individually replayed and the payload checked: 89 valid HTML responses (12,872,299 bytes) are saved as hashed source files, while two July 2008 responses still fail gzip decoding. The valid rows resolve to 88 distinct capture timestamps; requested and resolved dates remain separate in the index. The gallery generates a local page for every validated response, but the snapshots have not each been visually reviewed by a person.

The page captures expose 1,561 unique image/media and stylesheet URLs: 1,428 images/media URLs and 133 CSS URLs. Exact CDX lookups were completed for all 1,561. Seven bounded retries checked 280 previously rate-limited URLs and found 60 additional capture-bearing URLs; nine later rotated retries and a fresh 25-URL rotated batch added no new captures. Wayback now has rows for 213 image/media URLs and all 133 stylesheets (346 URLs total). The recovery pipeline has 210 validated images/media items, 133 stylesheets, and two validated legacy Flash binaries: 345 recovered asset URLs, 316 served image, stylesheet, and Flash files, and 18,763,409 bytes. This includes seven inline MySpace default-cover images and a profile icon that the initial asset scan missed. The latest image addition is a 2007 profile image captured at `20070616041026` (2,563 bytes; SHA-256 `a5a5585b7c11c45adb6f92f0f91e325acf9dc26c4e3c1c426cd1779ac6ed88ab`). Two MySpace Flash player files are now stored with their dated capture provenance and checksums. The original players are never embedded or executed; seven dated profile pages provide local download links. The sole remaining rejected payload is `www.masslinemedia.com/images/myspacebg.gif`, whose only indexed response is HTML rather than GIF bytes. A separate CDX query on the non-`www` host resolves to that same 575-byte HTML response, not an alternate image. Captured CSS is stored locally; active imports and automatic external URL references are stripped from the rendered archive so page loading does not contact the original hosts.

Of the remaining image/media lookups, 1,126 remain rate-limited by Wayback (HTTP 429), and 89 indexed URLs have no capture row. A fresh 25-URL rotated retry batch cleared five prior rate-limit errors into successful no-capture results but found no new capture-bearing URLs. The retry cursor is preserved for a later cooldown window; these results do not prove that the original media never existed. A deeper scan of the captured profile markup also preserved 26 RTMPE song-stream records with track/album metadata and one video record (“Carnage: Five Minutes to the Stage”). Wayback returned 13 dated HLS master-manifest responses for that video; all 13 small playlist bodies are saved and checksummed in [`streaming-media.json`](../../recovery/myspace-blue-scholars/index/streaming-media.json). Their referenced variant playlists have no captures, so the video cannot be played from these manifests. A sample exact audio URL has no Wayback record, host wildcard queries returned no successful rows, and Common Crawl returned no rows for a sample M4A URL in three tested collections (with one timeout), and a host-wide 2014 index query also found no audio captures; an exact HLS master query found no Common Crawl record. Audio files and video segments remain documented gaps. These responses are labeled as undated origin material, not Wayback captures.

The 89 local snapshots preserve captured profile text, comments, inline styles and dated appearance, while scripts, forms and interactive players are disabled. The MySpace page gallery has not received human visual review; the broader restoration remains an unreviewed candidate and the Pages release gate remains closed.
