Post by: sergio on September 27, 2007, 09:17:17 pm
any of the square stuff is my sx-70 with 600 film, and the peelapart is a 220 land camera using 667, 690 or 672 film.

if you're using the sx-70, know that the time-zero film that its made for isnt manufactured anymore except in the netherlands so its $$$$$. 600 film, the more common kind, is a few stops faster than timezero so you need to modify the sx-70 to use it. you can pop off the ring over the electronic eye and remove the neutral density filter and put the ring back on which is really easy, but be sure to set the knob all the way to darken when shooting. that should only make it like 0.1+EV.
