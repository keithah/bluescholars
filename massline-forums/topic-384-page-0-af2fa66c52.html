Title: Re: Artwork
Post by: sergio on April 29, 2007, 02:11:12 pm
cs3 is leaps and bounds better, at least for its intended purpose (photo editing). the built in RAW conversion is 10x better than any previous version. the curves feature added a histogram and the ability to independently adjust individual color channels. the new black and white conversion tool adds a lot more control to your color --> BW adjustments. the new smart select tool is amazing, and when used with the 'refine selection' tool you can get some really clean selections with little work. still not as precise as doing it manually with the pen tool. the smart filters are just great, using them like layers. also the new interface takes some getting used to (as you close out of palettes, etc, the image you are working on increases to the max size it can show). overall this is a MAJOR improvement over CS2.
